# LoginApp

## Descripción

LoginApp es una aplicación básica para Android desarrollada utilizando **Kotlin y Jetpack Compose**. El proyecto fue creado con el objetivo de practicar la construcción de interfaces de usuario y la navegación entre diferentes pantallas.

La aplicación cuenta con dos pantallas principales:

* **Inicio de sesión:** permite introducir un nombre de usuario y una contraseña.
* **Registro:** permite introducir nombre completo, nombre de usuario y contraseña.

La aplicación permite navegar entre ambas pantallas. En esta versión no se realiza almacenamiento de usuarios ni autenticación real.

## Tecnologías utilizadas

* Android Studio
* Kotlin
* Jetpack Compose
* Material Design 3
* Git
* GitHub

## Funcionalidades

* Pantalla de inicio de sesión.
* Pantalla de registro.
* Logo de la aplicación.
* Campo de nombre de usuario.
* Campo de contraseña.
* Campo de nombre completo en el registro.
* Navegación de Inicio de sesión a Registro.
* Navegación de Registro a Inicio de sesión.

## Requisitos

Para ejecutar el proyecto se recomienda contar con:

* Android Studio.
* Android SDK instalado.
* API 24 o superior.
* Emulador Android o dispositivo físico.

## Instrucciones para ejecutar el proyecto

1. Descargar o clonar este repositorio.
2. Abrir la carpeta del proyecto en Android Studio.
3. Esperar a que Gradle termine de sincronizar los archivos.
4. Seleccionar un dispositivo virtual o conectar un dispositivo Android.
5. Presionar el botón **Run** de Android Studio.
6. Esperar a que la aplicación se instale y ejecute.
7. Utilizar los enlaces de las interfaces para navegar entre Inicio de sesión y Registro.
